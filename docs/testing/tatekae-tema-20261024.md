# 立替の手間の確かめ(机の上・2026-10-24)

職人と統括(藤田建装)の両方の手間を、同じ架空のひと月の上に並べた。
数えたのは「指が触る回数」(押す・入れる)。統括の側の分・時間は、まだ確かめていない(下の「確かめること」)。

## 前提(船長の答え・10-24 夜)

- 藤田建装は、施設の駐車代・負担金を会社でまとめて払い、職人の請求書から引いている
- 職人ごとの駐車代は「駐車チケットを渡した記録(誰に何枚)」で分けている
- だからポンの駐車代も、受け取ったチケットから下書きする(現場に入った日からは作らない)

## 架空のひと月

M1070 架空の店。駐車チケット20枚を月の初めに一回で受け取る(施設の指針では月単位で申し込み、内監定例で配られる)。
時間外が2回、エレベーターの使用が1回。受け取った枚数が1枚違っていて、あとで直す。

## 職人の側(Senlings のポン)

| 場面 | 回数 | 触ること |
| --- | --- | --- |
| 最初の一回だけ:単価を入れる | 1 | 施設・ポン・単価・立て替える人・残す(5) |
| チケットを受け取った | 1 | 施設・ポン・枚数・受け取った(4)。日付は今日が入っている |
| 時間外を足す | 2 | 施設・ポン・＋・金額・一行足す(5)×2 |
| エレベーターを足す | 1 | 施設・ポン・＋・種類・金額・一行足す(6) |
| 違う行を直す | 1 | 施設・ポン・直す・金額・残す(5) |
| 月末の請求書 | 1 | ホーム・今月の請求書を作る・Excel(3)。差し引きの一行と別紙「立替内訳」は自動で入る |

ひと月で 28 回(最初の月は単価の 5 回を足して 33 回)。そのうち 16 回が、時間外とエレベーターの行を手で足す分。

いま(Senlings なし)の職人は、触らない代わりに、会社が引いた額を自分で確かめる手立てがない。

## 統括の側(藤田建装)

| いまの流れ | Senlings が入ると |
| --- | --- |
| 施設へまとめて払う | 変わらない(澪の領分) |
| チケットを誰に何枚渡したかを記録する | 変わらない。職人の側も同じものを持つようになる |
| 時間外・エレベーターの負担金を、誰の分か割り振る | 変わらない |
| 職人の請求書から引く額を、職人ごとに計算して照らし合わせる | 請求書に「差し引き(立替)」の一行と内訳の別紙が付いて届く。統括は自分の記録と合っているかを見るだけ |
| 合わないときの問い合わせ・説明 | 同じチケットの記録から作っているので、合わないことが減るはず(未確認) |

## 分かったこと

1. 職人の手間の半分以上は、時間外とエレベーターの行を手で足すところ。「残業おつかれさま」を押した日に時間外の行を下書きする形(設計済み・未実装)ができれば、ここは確かめるだけになる
2. さらに、統括が施設から受けた負担金を「申し送りの封筒」で職人に届ければ(澪 → Senlings の Push)、職人はほぼ「合っているか見る」だけになる。封筒の受け口の置き場所は、まだ決めていない
3. 統括の得は「計算と照らし合わせ」が「見るだけ」になること。ただし割り振りの手間は残る

## 確かめること

- 統括の側:いま一人の職人あたり、月にどれくらいの時間を差し引きの計算と照らし合わせに使っているか(藤田建装に聞く)
- 時間外の負担金(区画・時間あたり)を、複数の職人でどう割っているか
- 差し引きの行の消費税と、インボイス(適格請求書)にあたる書類が要るか(税理士さん)
- Excel の書き出しは、SheetJS の代役で中身を確かめただけ。実際に書き出したファイルを開いて、別紙と差し引きの行の見え方を確かめる(端末で)
